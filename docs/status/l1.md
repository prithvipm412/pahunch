# L1 · Claude Code status

## Done

- Replaced the fake solver with a real Modified Nodal Analysis (MNA) solver in `src/physics`.
  - Wires and closed switches merge grid points via union-find; open switches are removed.
  - Batteries are stamped as their Norton equivalent (default 3 V, fixed 0.5 Ω internal
    resistance) so no extra branch-current unknowns are needed; bulbs/resistors default to 10 Ω.
  - Current through zero-resistance wires/closed switches (not directly observable from node
    voltages) is recovered via a per-island spanning-tree subtree-sum of the surrounding
    resistor/bulb/battery currents; redundant/parallel wire edges report 0 (indeterminate split).
  - Bulb state uses `ratio = power / (3^2 / R_bulb)` with thresholds: off < 5%, dim < 50%,
    normal < 150%, bright < 300%, overload ≥ 300%.
  - `src/physics/validate.ts` detects `empty`, `no_battery`, `short_circuit` (direct wire-merge of
    battery terminals, or post-solve battery current > 2 A), `open_circuit` (battery has no closed
    loop excluding its own edge), and `floating:<id>` warnings for components not connected to a
    battery-containing island.
  - `solve()` never throws — singular-matrix / unexpected-error paths fall back to an `ok:false`
    result with every component reported off.
- Added 10 fixtures under `src/contracts/fixtures/` covering single bulb, series/parallel bulbs,
  open/closed switch, bulb+resistor, short circuit, broken wire, mixed series-parallel, and two
  batteries in series — exercised by `src/physics/solve.test.ts` along with series-vs-parallel
  current comparison and a 200-trial randomized-netlist fuzz test.
- `solve()`'s signature is unchanged.
