# L2 · Codex status

## Done

- Added the localized home shell, Build mode circuit editor, solver result display, and shared audio utilities.
- Added 192px, 512px, and maskable 512px navy and white P PWA icons in `public/icons/` and referenced them in the manifest.
- Phase 2: Build accepts Draw's router-state netlist and shows a drawing-origin note; Predict first passes `{ netlist, mode: 'predict' }` to Learn.
- Added English and simple Kannada strings for all Home and Build labels, mobile gesture audio unlock, undo, accessible grid touch targets, and friendly empty/no-battery/open/short circuit messages.
- Configured the service worker to fall back to `/index.html` for app routes and skip `/api/` requests.
- Phase 1 and 2 typecheck, tests, and production build passed.
- Phase 3: Wire is a sticky tray tool with pointer drag drawing, adjacent path expansion, collision avoidance, live preview, and one-step undo per drag chain.
- Added editable battery, resistor, bulb-resistance, and switch controls. Component value labels appear on the grid, and edits re-run the active solve immediately.
- Added five pure wire-path unit tests for skipped dots, vertical paths, diagonal rejection, backtracking, and occupied-part collisions.
- Phase 4: Build grid stays fixed while centered value dialogs open as fixed overlays. App touch-action prevents double-tap zoom, and all buttons and form controls use at least 16px text.
- Battery and resistor placement opens a localized value picker with the requested defaults and presets. Tapping existing parts opens the same editor; switches expose open/closed and every part can be deleted.
- Parts can be dragged to a snapped grid segment with green/red placement feedback. New placements and moves reject segment and symbol overlaps.
- Wire drag paths now expand skipped dots and remove path segments when backtracking over previous dots; the live wire chain updates while dragging and remains one undo action.
- `npm run typecheck`, `npm test` (74 tests), and `npm run build` pass.
