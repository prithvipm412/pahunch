**What works (Fault Hunt):**
- 3 puzzles from `src/learn/puzzles.ts`.

- Student taps a component in the SVG (all parts are tappable).

- Wrong → plays `fault_wrong`; after 2 wrong tries plays `fault_hint` with the puzzle's hint text.

- Puzzle progress dots at the bottom. "Try another" cycles through all 3 puzzles.

**What works (Offline queue):**

- On browser `online` event, `useOfflineQueue` drains the queue entry-by-entry.
- While draining, a banner shows "Sending saved circuits…".
- A gold badge in the Draw header shows the count of queued images.

**What works (i18n):**
- All visible strings on Draw and Learn screens are in `content/i18n/draw.json` and `content/i18n/learn.json`.

## Running the API locally

```bash
# 1. Install Vercel CLI globally (or use npx)
npm i -g vercel

# 2. Create a local env file — NEVER commit this
echo 'GEMINI_API_KEY=your_key_here' >> .env.local
# Optionally override the model:
echo 'GEMINI_MODEL=gemini-2.0-flash' >> .env.local

# 3. Start the dev server (runs both Vite frontend and Vercel API routes)
npx vercel dev
# → http://localhost:3000

# Without a key the app still works — /api/scan returns a demo netlist
# with the X-Demo: 1 header and a banner in the UI.
```

> **Never commit `.env.local`** — it is in `.gitignore` by default from Vercel templates.
> The `GEMINI_API_KEY` is read **only** inside `api/scan.ts` on the server; it is never sent to the client.

## Interface changes

- **`/api/scan`** — Vercel serverless endpoint (Phase 1).
  - `POST { image: string (base64 JPEG), hint?: string }` → `Netlist` JSON
  - On success without key: `200 { ...netlist }` + `X-Demo: 1` header
  - On error: `{ error: string }` with appropriate HTTP status

- **`/build` route state** — Draw mode calls `navigate('/build', { state: { netlist } })`.
  L2 (Build) should read `useLocation().state?.netlist` and pre-populate the canvas.

- **`/learn` route state** — Learn Predict tab accepts `{ netlist, mode: 'predict' }` sent from Build mode via `navigate('/learn', { state: { netlist, mode: 'predict' } })`. If not provided, the preset challenge picker is shown.

- **`tsconfig.api.json`** _(new file, root level)_ — TypeScript project config for the `api/` folder. Uses `"module": "nodenext"` / `"moduleResolution": "nodenext"` and `"types": ["node"]` so Vercel handler types resolve correctly. No new npm packages were installed.

- **`tsconfig.json`** _(modified, root level)_ — Added `{ "path": "./tsconfig.api.json" }` to the `references` array alongside the existing `tsconfig.app.json` and `tsconfig.node.json` entries, so `npm run typecheck` (`tsc -b`) covers `api/` as well.

- **`content/i18n/learn.json`** and **`content/i18n/draw.json`** _(new files)_ — Bilingual string tables (en/kn) for the Learn and Draw screens. All screen strings come from here; L2 may add new keys but should not change existing key names (the hooks will break).
